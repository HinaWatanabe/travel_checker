# 🐸 カエルの旅行チェッカー 🐸

47都道府県の訪問記録を管理し、旅をするたびにカエルが成長していくWebアプリです。


## 制作背景

旅行が好きで全国47都道府県制覇を目指しているため、
訪問記録を可視化できるアプリを制作しました。

また、カエルが好きなことから、旅をするたびにカエルが成長する仕組みや全国のカエルスポットを紹介する機能を実装しています。


## 主な機能

- 訪問した都道府県と日付の記録
- 訪問履歴の一覧表示・削除
- 日本地図上で訪問済み地域を色分け表示
- 訪問回数に応じたカエルの成長機能
- 日替わりおすすめスポットの表示
- LocalStorageによるデータ永続化


## 使用技術

| 技術 | 用途 |
|------|------|
| HTML | 画面構造 |
| CSS | レイアウト・デザイン |
| JavaScript | データ管理・DOM操作 |
| LocalStorage | データ永続化 |
| SVG Map | 日本地図の表示 |


## 工夫した点

- Geoloniaが公開している日本地図SVGを活用し、訪問状況を視覚的に把握できるようにした
- JavaScriptでSVG要素を操作し、訪問データと連動して地図の色を変更
- LocalStorageを活用し、ブラウザを閉じても記録を保持
- 日付をもとにしたシード値を利用し、毎日異なるおすすめスポットを表示
- 楽しさを加えるため、カエルの成長機能を実装
